# Data

Put the ESA Kelvins Collision Avoidance Challenge files here, or set `NEEDLE_DATA_DIR` to their folder:

- `train_data.csv` (162,634 rows, 13,154 events)
- `test_data.csv` (24,484 rows, 2,167 events; every row is at least 2 days before closest approach)

This folder is git-ignored. Do not commit the CSVs.
